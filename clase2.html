INGENIERÍA DE PROMPTS PARA POWER BI (DAX)

Las 4 Reglas para que Copilot Escriba Código DAX que Funcione a la Primera

En Excel las fórmulas miran celdas sueltas (`I2`, `H2`); en cambio, en Power BI (lenguaje DAX) las medidas operan sobre Columnas Completas entre corchetes (`'Tabla'[Columna]`). Esto es lo que debes darle siempre a Copilot:

1️⃣ Tabla Exacta

Indica siempre el nombre exacto de la hoja o tabla entre comillas simples:
'2_Fact_Operaciones_BI'

2️⃣ Columnas Base

Nombra las columnas numéricas que debe sumar:
[Venta_Real_Soles]
[Cuota_Meta_Soles]

3️⃣ Función DIVIDE

Exige usar DIVIDE(num, den, 0) en lugar de / para que nunca aparezca "Infinity" o "NaN" en tiendas nuevas.

4️⃣ Separador Local

Si tu Power BI pide coma (,) o punto y coma (;), cámbialo arriba con el botón ⚙️ Separador DAX.

💡 ¿Dónde se pega una Medida DAX en Power BI Desktop? (En 2 clics)

En el panel derecho Datos, haz clic derecho sobre la tabla 2_Fact_Operaciones_BI → Nueva medida. Se abrirá la barra de fórmulas arriba (igual que en Excel): ahí pegas el código de Copilot y presionas Enter.

LAB 02 · FORMULACIÓN ASISTIDA POR COPILOT EN POWER BI

Genera las 3 Medidas DAX Fundamentales de la Operación

🤖 COPIAR Y PEGAR EN TU CHAT DE COPILOT
En mi modelo de Power BI Desktop tengo la tabla '2_Fact_Operaciones_BI' con las columnas numéricas: - [Venta_Real_Soles] - [Cuota_Meta_Soles] - [Visitas_Programadas] - [Visitas_CheckPDV_OK] Escríbeme 3 medidas DAX listas para copiar y pegar (usando coma "," como separador de argumentos): 1) [% Cumplimiento Cuota]: División segura (DIVIDE) de la suma de Venta_Real_Soles entre la suma de Cuota_Meta_Soles, devolviendo 0 si hay error. 2) [Brecha Meta S/]: Diferencia entre la suma de Venta_Real_Soles menos la suma de Cuota_Meta_Soles. 3) [% Cobertura CheckPDV]: División segura (DIVIDE) de la suma de Visitas_CheckPDV_OK entre la suma de Visitas_Programadas.

✅ Pega cada Medida en Nueva medida:

1. Medida % Cumplimiento Cuota (Formato %):

% Cumplimiento Cuota = DIVIDE(SUM('2_Fact_Operaciones_BI'[Venta_Real_Soles]), SUM('2_Fact_Operaciones_BI'[Cuota_Meta_Soles]), 0)

2. Medida Brecha Meta S/ (Formato Moneda S/):

Brecha Meta S/ = SUM('2_Fact_Operaciones_BI'[Venta_Real_Soles]) - SUM('2_Fact_Operaciones_BI'[Cuota_Meta_Soles])

3. Medida % Cobertura CheckPDV (Formato %):

% Cobertura CheckPDV = DIVIDE(SUM('2_Fact_Operaciones_BI'[Visitas_CheckPDV_OK]), SUM('2_Fact_Operaciones_BI'[Visitas_Programadas]), 0)
LAB 03 · MEDIDAS DAX DE IMPACTO VISUAL (EL SECRETO DE LOS DASHBOARDS PRO)

Semáforo Ejecutivo con SWITCH(TRUE()) y Título Dinámico Inteligente

¿Cómo logramos que una matriz de Power BI muestre automáticamente alertas visuales **🟢 / 🟡 / 🔴** y que el título del reporte cambie solo al elegir una Zona o Supervisor? Con estas dos medidas generadas por Copilot:

🤖 PROMPT PARA SEMÁFORO Y TÍTULO DINÁMICO
Usando la medida [% Cumplimiento Cuota] que ya creamos en la tabla '2_Fact_Operaciones_BI', escríbeme 2 medidas DAX adicionales: 1) [Semaforo Cumplimiento]: Usa una variable VAR Pct = [% Cumplimiento Cuota] y la función SWITCH(TRUE(), ...) para devolver: - Si Pct >= 1: "🟢 SOBRECUMPLE (>=100%)" - Si Pct >= 0.90: "🟡 EN RIESGO (90%-99%)" - Si es menor a 0.90: "🔴 CRITICO (<90%)" 2) [Titulo Dinamico Dashboard]: Usa SELECTEDVALUE('2_Fact_Operaciones_BI'[Zona_Geografica], "Todas las Zonas Nacionales") para mostrar un texto dinámico con la zona seleccionada y su % de cumplimiento formateado con FORMAT([% Cumplimiento Cuota], "0.0%").

Macro en Word para Sellar Pie de Página y Exportar a PDF con 1 Clic

También puedes usar Alt + F11 directamente dentro de Microsoft Word. Esta macro agrega automáticamente el pie de página de confidencialidad de Adecco y exporta tu informe a un PDF inalterable con la fecha del día:

📄 CÓDIGO VBA PARA MICROSOFT WORD — Sub ExportarInformePDF_Adecco()
Sub ExportarInformePDF_Adecco() Dim rutaCarpeta As String Dim nombrePDF As String Dim sec As Section ' 1. Insertar pie de pagina corporativo automatico en todas las secciones For Each sec In ActiveDocument.Sections With sec.Footers(1).Range ' 1 = wdHeaderFooterPrimary .Text = "ADECCO PERU S.A. · Sales & Marketing | Informe Ejecutivo Confidencial | Generado el " & Format(Date, "dd/mm/yyyy") .Font.Name = "Segoe UI" .Font.Size = 8.5 .Font.Color = RGB(100, 116, 139) .ParagraphFormat.Alignment = 1 ' Centrado End With Next sec ' 2. Definir carpeta de salida (Escritorio o carpeta del documento) If Len(ActiveDocument.Path) > 0 Then rutaCarpeta = ActiveDocument.Path & Application.PathSeparator Else rutaCarpeta = CreateObject("WScript.Shell").SpecialFolders("Desktop") & Application.PathSeparator End If nombrePDF = rutaCarpeta & "Informe_Ejecutivo_Adecco_SM_" & Format(Date, "yyyymmdd") & ".pdf" ' 3. Exportar a PDF de alta calidad y abrirlo en pantalla ActiveDocument.ExportAsFixedFormat OutputFileName:=nombrePDF, _ ExportFormat:=17, _ OpenAfterExport:=True MsgBox "¡Informe Ejecutivo sellado y exportado con exito a PDF!" & vbCrLf & nombrePDF, vbInformation, "Adecco AI Co-Pilot Lab" End Sub
